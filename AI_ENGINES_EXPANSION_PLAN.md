## 🏗️ ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

### **Файловая структура:**
```
backend/
├── engines/
│   ├── base-engine.js           # Базовый интерфейс
│   ├── claude-engine.js         # Wrapper для Claude
│   ├── openai-engine.js         # OpenAI реализация

│   └── engine-dispatcher.js     # Диспетчер провайдеров
├── services/
```
