2. Выбрать подразделение из списка

4. **Выбрать AI провайдер** (Claude или OpenAI)

### Шаг 3: Проверка доступности провайдеров
```bash

curl -s https://madlen.space/api/admin/ai-recommendations/providers | jq .

# - openai: available: true
```

1. Нажать **"Запустить анализ"**
2. Дождаться завершения (1-3 минуты)
3. Проверить результаты каждого агента

## ✅ Критерии успешного тестирования

### **До исправления (НЕ должно быть):**
- ❌ "Пожалуйста, предоставьте данные для анализа"
- ❌ "Нужны данные для проведения анализа"
- ❌ "Данные отсутствуют"
- ❌ Общие рекомендации без конкретных цифр

### **После исправления (должно быть):**
- ✅ Конкретные цифры из данных подразделения
- ✅ Анализ продаж по дням с суммами
- ✅ Анализ отзывов с конкретными фразами
- ✅ Рекомендации на основе реальных данных

## 🎯 Что проверить в каждом агенте

### **1. SalesAnalysisAgent** 📈
**Должен анализировать:**
- Конкретные суммы продаж по дням
- Отклонения план/факт с процентами
- Пиковые и слабые часы продаж
- Конкретные даты и периоды

**Пример правильного ответа:**
```
"Анализ показывает, что 15.07.2025 выручка составила 920,000 тенге, 
что на 7.6% меньше плана. Пиковые продажи наблюдались в 19:00-20:00 
со средним чеком 4,500 тенге."
```

### **2. PayrollAnalysisAgent** 💰
**Должен анализировать:**
- Конкретные суммы ФОТ сотрудников
- Количество смен и эффективность
- Соотношение затрат и выручки
- Имена конкретных сотрудников

### **3. StaffingAgent** 👥
**Должен анализировать:**
- Загрузку персонала по часам
- Пики и провалы в рабочем графике
- Конкретные рекомендации по оптимизации смен

### **4. ReputationAgent** ⭐
**Должен анализировать:**
- Конкретные отзывы клиентов
- Повторяющиеся жалобы и проблемы
- Конкретные фразы из отзывов
- Рейтинги и оценки

**Пример правильного ответа:**
```
"Анализ 50 отзывов показывает основные проблемы: 'долго ждали заказ' 
(упоминается в 12 отзывах), 'холодная еда' (8 отзывов). 
Положительные отзывы отмечают 'быстрое обслуживание' и 'вкусные манты'."
```

### **5. OptimizationAgent** 🎯
**Должен давать:**
- Конкретные шаги по улучшению
- Рекомендации на основе анализа других агентов
- Приоритизированный список действий

### **6. NarrativeAgent** 📊
**Должен создавать:**
- Итоговый отчет для управляющего
- Резюме по всем разделам
- Конкретные выводы и рекомендации

## 🚨 Признаки проблем

### **Если агент просит данные:**
```
"Пожалуйста, предоставьте данные для анализа"
"Для проведения анализа мне нужны следующие данные"
"Данные отсутствуют или неполные"
```
**→ Проблема НЕ исправлена**

### **Если агент дает общие советы:**
```
"Рекомендуется улучшить качество обслуживания"
"Необходимо оптимизировать рабочие процессы"
"Следует обратить внимание на клиентский сервис"
```
**→ Проблема НЕ исправлена**
