## 🚀 Как использовать OpenAI провайдер

### 1. Вход в систему
1. Перейдите на https://madlen.space/
2. Введите пароль: `admin12qw`
3. Выберите раздел **"AI рекомендации"**

### 2. Выбор провайдера
1. В выпадающем списке выберите **"OpenAI GPT-4"**
2. Выберите подразделение для анализа
3. Установите даты периода (не более 30 дней)
4. Нажмите **"🤖 Запустить анализ"**

### 3. Ожидание результатов
- **OpenAI быстрее**: 3-8 секунд на агента
- **Общее время**: 1-3 минуты для полного анализа
- **При долгом ожидании**: система автоматически проверит результаты

## 🛠️ Если возникают проблемы

### Очистить кэш браузера:
1. **Chrome/Edge**: Ctrl+Shift+R (принудительное обновление)
2. **Firefox**: Ctrl+F5
3. **Safari**: Cmd+Shift+R

### Проверить статус системы:
- Откройте https://madlen.space/api/health
- Должен показать: `{"status":"OK"}`

### Если анализ не запускается:
1. Обновите страницу (F5)
2. Попробуйте другой провайдер (Claude)
3. Проверьте, не запущен ли уже другой анализ
