- **Реальные интервалы в логах:** 3-35 секунд

## Основные проблемы

### 1. Недостаточные задержки для ошибок 529
Текущие задержки (15s, 45s, 90s) слишком короткие для перегруженного API Claude.

### 2. Слишком частые запросы между агентами
Паузы в 10-25 секунд недостаточны, когда API перегружен.

### 3. Отсутствие адаптивной логики
Система не учитывает, что при участившихся ошибках 529 нужно увеличивать все задержки.

### 4. Недостаточная защита Circuit Breaker
Circuit breaker открывается только после 3 ошибок подряд, но ошибки 529 могут возникать чаще.

### 3. Добавить адаптивную логику
```javascript
// Если за последние 10 минут было 3+ ошибок 529
```
