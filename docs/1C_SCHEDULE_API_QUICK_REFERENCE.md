# 📋 Быстрая справка: API импорта графиков с организациями

## Endpoint
```
POST https://madlen.space/api/admin/schedules/import-1c
Content-Type: application/json
Max Size: 500 MB
```

## Минимальный пример

```json
{
  "ДатаВыгрузки": "2025-11-15",
  "КоличествоГрафиков": 1,
  "Графики": [
    {
      "НаименованиеГрафика": "График 5/2",
      "КодГрафика": "uuid-графика",
      "Организации": ["230540000699", "221040029729"],
      "РабочиеДни": [
        {
          "Дата": "2025-11-15",
          "Месяц": "2025-11-01",
          "ВидУчетаВремени": "Рабочий день",
          "ДополнительноеЗначение": 8,
          "ВремяНачалоРаботы": "09:00:00",
          "ВремяЗавершениеРаботы": "18:00:00"
        }
      ]
    }
  ]
}
```

## Код 1С (минимум)

```bsl
// Подготовка данных
График = Новый Структура;
График.Вставить("НаименованиеГрафика", "График 5/2");
График.Вставить("КодГрафика", Строка(ГрафикСсылка.УникальныйИдентификатор()));

// 🆕 Организации (массив БИНов)
МассивБИН = Новый Массив;
МассивБИН.Добавить("230540000699");
МассивБИН.Добавить("221040029729");
График.Вставить("Организации", МассивБИН);

// Рабочие дни
РабочиеДни = Новый Массив;
// ... добавление дней
График.Вставить("РабочиеДни", РабочиеДни);

// Отправка
ДанныеЗапроса = Новый Структура;
ДанныеЗапроса.Вставить("ДатаВыгрузки", Формат(ТекущаяДата(), "ДФ=yyyy-MM-dd"));
ДанныеЗапроса.Вставить("КоличествоГрафиков", 1);

МассивГрафиков = Новый Массив;
МассивГрафиков.Добавить(График);
ДанныеЗапроса.Вставить("Графики", МассивГрафиков);

// JSON + HTTP
ЗаписьJSON = Новый ЗаписьJSON;
ЗаписьJSON.УстановитьСтроку();
ЗаписатьJSON(ЗаписьJSON, ДанныеЗапроса);
JSON = ЗаписьJSON.Закрыть();

Соединение = Новый HTTPСоединение("madlen.space", 443);
Запрос = Новый HTTPЗапрос("/api/admin/schedules/import-1c");
Запрос.Заголовки.Вставить("Content-Type", "application/json");
Запрос.УстановитьТелоИзСтроки(JSON, КодировкаТекста.UTF8);

Ответ = Соединение.ВызватьHTTPМетод("POST", Запрос);
```

## Обязательные поля

| Поле | Формат | Пример |
|------|--------|--------|
| ДатаВыгрузки | YYYY-MM-DD | "2025-11-15" |
| НаименованиеГрафика | Строка | "График 5/2" |
| КодГрафика | UUID | "550e8400-e29b..." |
| Дата | YYYY-MM-DD | "2025-11-15" |
| Месяц | YYYY-MM-01 | "2025-11-01" |
| ВидУчетаВремени | Строка | "Рабочий день" |
| ДополнительноеЗначение | Число | 8 |

## Опциональные поля

| Поле | Формат | Пример | Описание |
|------|--------|--------|----------|
| **Организации** | **Массив строк** | **["БИН1", "БИН2"]** | **🆕 Массив БИНов (12 цифр)** |
| ВремяНачалоРаботы | HH:MM:SS | "09:00:00" | Время начала |
| ВремяЗавершениеРаботы | HH:MM:SS | "18:00:00" | Время окончания |

## Ответ сервера

### Успех (200)
```json
{
  "success": true,
  "message": "Импорт завершен успешно",
  "statistics": {
    "totalSchedulesReceived": 10,
    "totalSchedulesProcessed": 10,
    "totalWorkDaysInserted": 3650
  }
}
```

### Ошибка (400)
```json
{
  "success": false,
  "error": "Нет данных для импорта"
}
```

## Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| HTTP 400 | Пустой массив графиков | Проверить `Графики.Количество() > 0` |
| HTTP 400 | Неверный JSON | Валидировать через jsonlint.com |
| HTTP 500 | Ошибка БД | Связаться с администратором |
| Несуществующие БИНы | БИН не найден в системе | Проверить БИНы организаций |
