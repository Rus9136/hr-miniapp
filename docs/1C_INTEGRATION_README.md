### Поддержка нескольких организаций для одного графика

Теперь при импорте графиков работы из 1С можно указать массив организаций (БИНов), к которым относится график. Это позволяет:
- Использовать один график в нескольких организациях
- Явно задавать связи графиков с организациями
- Гибко управлять распределением графиков

**Пример:**
```json
{
  "НаименованиеГрафика": "График 5/2",
  "КодГрафика": "uuid-графика",
  "Организации": ["230540000699", "221040029729", "210640037797"]
}
```

## 🚀 Быстрый старт

### Шаг 1: Ознакомление

Прочитайте [быструю справку](1C_SCHEDULE_API_QUICK_REFERENCE.md) для понимания базовой структуры запроса.

### Шаг 2: Подготовка данных

Определите, как вы будете получать список организаций для графика:
- **Вариант А:** Организации хранятся в табличной части справочника "ГрафикиРаботы"
- **Вариант Б:** Организации определяются через сотрудников, использующих график

### Шаг 3: Импорт обработки

1. Скопируйте код из [1C_ВыгрузкаГрафиковВHR.bsl](1C_ВыгрузкаГрафиковВHR.bsl)
2. Создайте новую обработку в 1С
3. Вставьте код в модуль обработки
4. Адаптируйте функцию `ПолучитьОрганизацииДляГрафика()` под вашу структуру данных
5. Реализуйте функцию `ПолучитьДанныеДняГрафика()` для вашего графика

### Шаг 4: Тестирование

1. Выберите один тестовый график
2. Запустите выгрузку за небольшой период (1 неделя)
3. Проверьте логи в журнале регистрации 1С
4. Убедитесь в успешном импорте

### Шаг 5: Промышленная эксплуатация

После успешного тестирования:
1. Настройте регламентное задание для автоматической выгрузки
2. Определите периодичность выгрузки (рекомендуется: раз в сутки)
3. Настройте мониторинг успешности выгрузки

## 🔧 Адаптация под вашу конфигурацию

### Настройка получения организаций

В файле [1C_ВыгрузкаГрафиковВHR.bsl](1C_ВыгрузкаГрафиковВHR.bsl) найдите функцию `ПолучитьОрганизацииДляГрафика()` и выберите подходящий вариант:

#### Вариант 1: Табличная часть в справочнике

```bsl
// Если у вас есть табличная часть "Организации" в справочнике "ГрафикиРаботы"
Для Каждого СтрокаОрг Из ГрафикСсылка.Организации Цикл
    БИН = СокрЛП(СтрокаОрг.Организация.ИНН);
    Если ПроверитьБИН(БИН) Тогда
        МассивБИН.Добавить(БИН);
    КонецЕсли;
КонецЦикла;
```

#### Вариант 2: Через сотрудников

```bsl
// Если организации определяются через сотрудников
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ РАЗЛИЧНЫЕ
|    Сотрудники.Организация.ИНН КАК БИН
|ИЗ
|    Справочник.Сотрудники КАК Сотрудники
|ГДЕ
|    Сотрудники.ГрафикРаботы = &График";

Запрос.УстановитьПараметр("График", ГрафикСсылка);
```

### Настройка получения данных дня

Реализуйте функцию `ПолучитьДанныеДняГрафика()` в соответствии с вашей структурой хранения графиков.

## 🔍 Диагностика проблем

### Проблема: Несуществующие БИНы организаций

**Симптомы:**
```
Предупреждение: Несуществующие БИНы организаций для графика 'График 5/2': 999999999999
```

**Решение:**
1. Проверьте правильность БИНов в 1С (должно быть 12 цифр)
2. Убедитесь, что организации с этими БИНами синхронизированы в HR систему
3. Проверьте соответствие поля БИН/ИНН (используется поле с 12 цифрами)

### Проблема: HTTP 400 - Пустой массив графиков

**Симптомы:**
```
Ошибка: Нет данных для импорта. Массив "Графики" отсутствует или пуст.
```

**Решение:**
1. Убедитесь, что `МассивГрафиков.Количество() > 0`
2. Проверьте логику отбора графиков
3. Убедитесь, что графики не помечены на удаление

### Проблема: HTTP 500 - Ошибка сервера

**Решение:**
1. Свяжитесь с администратором HR системы
2. Предоставьте время запроса и данные графика
3. Проверьте логи сервера

### Проблема: Timeout при отправке большого количества графиков

**Решение:**
1. Разбейте выгрузку на пакеты (по 50-100 графиков)
2. Увеличьте timeout в настройках HTTPСоединение
3. Оптимизируйте период выгрузки (не выгружать весь год за раз)

## 📊 Примеры использования

### Выгрузка всех графиков за текущий год

```bsl
НачалоГода = НачалоГода(ТекущаяДата());
КонецГода = КонецГода(ТекущаяДата());
ВыгрузитьГрафики(НачалоГода, КонецГода);
```

### Выгрузка конкретных графиков за месяц

```bsl
МассивГрафиков = Новый Массив;
МассивГрафиков.Добавить(Справочники.ГрафикиРаботы.НайтиПоНаименованию("График 5/2"));
МассивГрафиков.Добавить(Справочники.ГрафикиРаботы.НайтиПоНаименованию("График 2/2"));

Начало = НачалоМесяца(ТекущаяДата());
Конец = КонецМесяца(ТекущаяДата());
ВыгрузитьГрафики(Начало, Конец, МассивГрафиков);
```

### Регламентное задание (выгрузка каждую ночь)

```bsl
// Настройки регламентного задания:
// Расписание: Ежедневно в 02:00
// Процедура: ВыгрузкаГрафиковРегламентноеЗадание

Процедура ВыгрузкаГрафиковРегламентноеЗадание() Экспорт

    Попытка
        // Выгружаем графики на 3 месяца вперед
        НачалоПериода = НачалоМесяца(ТекущаяДата());
        КонецПериода = КонецМесяца(ДобавитьМесяц(НачалоПериода, 3));

        ВыгрузитьГрафики(НачалоПериода, КонецПериода);

    Исключение
        ЗаписьЖурналаРегистрации(
            "Регламентное задание: Выгрузка графиков в HR",
            УровеньЖурналаРегистрации.Ошибка,
            ,
            ,
            ОписаниеОшибки()
        );
    КонецПопытки;

КонецПроцедуры
```
