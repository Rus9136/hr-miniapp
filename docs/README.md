## 🔌 Интеграция с 1С - Быстрый старт

### Основные endpoints:

#### 1. Импорт графиков работы
```http
POST https://madlen.space/api/admin/schedules/import-1c
Content-Type: application/json

{
  "ДатаВыгрузки": "2025-10-11T10:30:00",
  "КоличествоГрафиков": 1,
  "Графики": [...]
}
```

#### 2. Обновление данных сотрудников
```http
POST https://madlen.space/api/admin/employees/update-iin
Content-Type: application/json

[
  {
    "table_number": "АП00-00467",
    "iin": "830909401891",
    "payroll": 212338.00
  }
]
```

#### 3. Назначение графиков
```http
POST https://madlen.space/api/admin/schedules/assign-employee
Content-Type: application/json

{
  "employee_number": "АП00-00467",
  "schedule_code": "f7167c0a-eebb-11ef-90da-3cecef8cc60b",
  "start_date": "2025-01-01"
}
```

## 📊 Архитектура данных

### Связь графиков работы и сотрудников:

```
EMPLOYEES                EMPLOYEE_SCHEDULE_ASSIGNMENTS        WORK_SCHEDULES_1C
(Сотрудники)            (Назначения графиков)                (Шаблоны графиков)
┌─────────────┐         ┌──────────────────────┐             ┌──────────────────┐
│ id          │         │ id                   │             │ id               │
│ table_number│◄────────┤ employee_number      │             │ schedule_code    │
│ full_name   │         │ schedule_code        ├────────────►│ schedule_name    │
│ iin         │         │ start_date           │             │ work_date        │
│ payroll     │         │ end_date             │             │ work_start_time  │
└─────────────┘         └──────────────────────┘             │ work_end_time    │
                                                              │ work_hours       │
                                                              └──────────────────┘
```

### Процесс работы:

1. **1С → HR System:** Импорт графиков работы (шаблоны на весь год)
2. **1С → HR System:** Обновление ИИН и ФОТ сотрудников
3. **1С → HR System:** Назначение графиков сотрудникам
4. **HR System:** Расчет фактических часов работы на основе событий входа/выхода
5. **HR System → Сотрудники:** Отображение календаря посещаемости в Telegram Mini App

## 🔑 Ключевые понятия

### График работы (work_schedules_1c)
- **Шаблон** расписания на целый год (365 записей)
- Каждая запись = один день (дата, время начала/конца, количество часов)
- Идентифицируется по `schedule_code` (UUID из 1С)
- Пример: "09:00-18:00/MG вх-сб,вс" - 8-часовой график с выходными в субботу и воскресенье

### Назначение графика (employee_schedule_assignments)
- Связывает **сотрудника** с **графиком работы**
- Указывает период действия: `start_date` → `end_date`
- `end_date = NULL` означает бессрочное назначение
- Один сотрудник может иметь несколько назначений (смена графика)

### Табельный номер (table_number)
- Уникальный идентификатор сотрудника (например: "АП00-00467")
- Используется для связи между таблицами
- Передается из 1С без изменений

### ИИН (Individual Identification Number)
- 12-значный индивидуальный идентификационный номер
- Используется для авторизации в системе
- Обновляется из 1С

### ФОТ (Фонд оплаты труда / Payroll)
- Зарплата сотрудника в тенге
- Используется для расчетов и AI-анализа
- Обновляется из 1С

## ⚠️ Важные замечания

### Для разработчиков 1С:

1. **Формат даты:** Всегда используйте `YYYY-MM-DD`
2. **Формат времени:** Всегда используйте `HH:MM:SS`
3. **Кодировка:** Обязательно UTF-8
4. **Content-Type:** `application/json; charset=utf-8`
5. **Таймаут:** Минимум 60 секунд (для больших выгрузок - 600 секунд)
6. **UUID графиков:** Используйте `УникальныйИдентификатор()` из 1С
7. **Размер пакета:** Рекомендуется 50-100 графиков за запрос
8. **HTTPS:** Обязательно использовать защищенное соединение

### Для системных администраторов:

1. **Порты:** Backend: 3030, Frontend: 5555, HTTPS: 443
2. **База данных:** PostgreSQL, порт 5432
3. **Docker volumes:** НИКОГДА не используйте `docker-compose down -v`
4. **Логи:** `/var/log/hr-miniapp/` или `docker-compose logs`
5. **Бэкапы:** Ежедневное резервное копирование БД
