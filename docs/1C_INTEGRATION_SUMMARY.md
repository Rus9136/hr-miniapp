## 🔌 Основные API endpoints

### 1️⃣ Импорт графиков работы
```
POST /api/admin/schedules/import-1c
```
- **Лимит:** 500MB
- **Таймаут:** 10 минут
- **Формат:** JSON с массивом графиков и рабочих дней

### 2️⃣ Обновление данных сотрудников
```
POST /api/admin/employees/update-iin
```
- **Данные:** ИИН, ФОТ (зарплата)
- **Формат:** Массив JSON объектов

### 3️⃣ Назначение графиков сотрудникам
```
POST /api/admin/schedules/assign-employee          (одиночное)
POST /api/admin/schedules/assign-employees-batch   (массовое)
```
- **Связывает:** Сотрудника с графиком работы
- **Период:** start_date → end_date (NULL = бессрочно)

### 4️⃣ Получение данных
```
GET /api/admin/schedules/1c/list              (список графиков)
GET /api/admin/schedules/1c                   (детали графика)
GET /api/admin/employees/schedules            (назначения)
```

## 📊 Структура данных

### Графики работы (work_schedules_1c):
- **158** уникальных графиков
- **33,518** записей дней
- Каждый график = шаблон на весь год (365 дней)

### Сотрудники (employees):
- **431** сотрудников с назначенными графиками
- Идентификация по **табельному номеру** (table_number)
- Поля: ИИН, ФОТ, подразделение, должность

### Назначения (employee_schedule_assignments):
- **2,133** активных назначений
- Связывает сотрудника с графиком
- Период действия: start_date → end_date

## 💡 Ключевые особенности

### ✅ Что система умеет:

1. **Импорт графиков из 1С** - до 500MB за запрос
2. **Обработка выходных дней** - автоматическое определение
3. **Ночные смены** - корректный расчет через полночь
4. **Массовые операции** - пакетная обработка данных
5. **Транзакции** - откат при ошибках
6. **Извлечение времени** - из названия графика если не передано
7. **Валидация данных** - проверка обязательных полей
8. **Детальное логирование** - отслеживание всех операций

### ⚡ Производительность:

- 1 график (365 дней) = **~2-3 секунды**
- 100 графиков = **~3-5 минут**
- 158 графиков (полная база) = **~5-8 минут**

| День недели | Время | Операция | Длительность |
|-------------|-------|----------|--------------|
| **Понедельник** | 02:00 | Полная синхронизация | ~10-15 мин |

## ⚠️ Важные моменты

### Обязательные требования:

✅ **Формат даты:** YYYY-MM-DD
✅ **Формат времени:** HH:MM:SS
✅ **Кодировка:** UTF-8
✅ **Content-Type:** application/json; charset=utf-8
✅ **Таймаут:** Минимум 60 секунд
✅ **HTTPS:** Обязательно защищенное соединение

### Типичные ошибки:

❌ Неправильный формат даты (DD.MM.YYYY вместо YYYY-MM-DD)
❌ Отсутствие обязательных полей (НаименованиеГрафика, КодГрафика)
❌ Слишком короткий таймаут (<60 секунд)
❌ Неправильная кодировка (не UTF-8)
❌ Отправка слишком большого пакета (>500MB)
