## 🎯 Обзор системы

HR Time Tracking система принимает данные из 1С по следующим направлениям:

```
┌──────────────┐
│     1С       │
│ Зарплата и   │
│  Управление  │
│  Персоналом  │
└──────┬───────┘
       │
       │ HTTP POST/GET (JSON)
       │
       ▼
┌─────────────────────────────────┐
│   HR Time Tracking System       │
│   https://madlen.space/api      │
├─────────────────────────────────┤
│ 1. Графики работы (расписания)  │
│ 2. Данные сотрудников (ИИН, ФОТ)│
│ 3. Назначения графиков          │
│ 4. Справочники                  │
└─────────────────────────────────┘
```

### Ключевые возможности:
- ✅ Импорт графиков работы (до 500MB за запрос)
- ✅ Обновление ИИН и ФОТ сотрудников
- ✅ Массовое назначение графиков
- ✅ Синхронизация подразделений, должностей
- ✅ Поддержка транзакций и откатов

## 📊 1. Импорт графиков работы

### Основной endpoint для импорта графиков из 1С

**Endpoint:** `POST /api/admin/schedules/import-1c`

**Лимиты:**
- Максимальный размер запроса: **500MB**
- Рекомендуемый размер пакета: до 100 графиков за запрос
- Timeout: 10 минут

### 📥 Структура запроса

```json
{
  "ДатаВыгрузки": "2025-10-11T10:30:00",
  "КоличествоГрафиков": 2,
  "Графики": [
    {
      "НаименованиеГрафика": "09:00-18:00/MG вх-сб,вс",
      "КодГрафика": "52a4bc15-eace-11ef-90da-3cecef8cc60b",
      "РабочиеДни": [
        {
          "Дата": "2025-10-11",
          "Месяц": "2025-10-01",
          "ВидУчетаВремени": "Рабочее время",
          "ДополнительноеЗначение": 8,
          "ВремяНачалоРаботы": "09:00:00",
          "ВремяЗавершениеРаботы": "18:00:00"
        },
        {
          "Дата": "2025-10-12",
          "Месяц": "2025-10-01",
          "ВидУчетаВремени": "В",
          "ДополнительноеЗначение": 0,
          "ВремяНачалоРаботы": null,
          "ВремяЗавершениеРаботы": null
        }
      ]
    },
    {
      "НаименованиеГрафика": "22:00-06:00/Ночная смена",
      "КодГрафика": "f7167c0a-eebb-11ef-90da-3cecef8cc60b",
      "РабочиеДни": [
        {
          "Дата": "2025-10-11",
          "Месяц": "2025-10-01",
          "ВидУчетаВремени": "Рабочее время",
          "ДополнительноеЗначение": 8,
          "ВремяНачалоРаботы": "22:00:00",
          "ВремяЗавершениеРаботы": "06:00:00"
        }
      ]
    }
  ]
}
```

### 📋 Описание полей

#### Корневой объект:
| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `ДатаВыгрузки` | String (DateTime) | Нет | Дата и время выгрузки из 1С |
| `КоличествоГрафиков` | Integer | Да | Количество графиков в массиве |
| `Графики` | Array | Да | Массив графиков работы |

#### Объект "График":
| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `НаименованиеГрафика` | String | Да | Название графика (например: "09:00-18:00/MG вх-сб,вс") |
| `КодГрафика` | UUID String | Да | Уникальный идентификатор графика из 1С |
| `РабочиеДни` | Array | Да | Массив рабочих дней (обычно 365 записей на год) |

#### Объект "РабочийДень":
| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `Дата` | String (DATE) | Да | Дата в формате YYYY-MM-DD |
| `Месяц` | String (DATE) | Да | Первое число месяца (YYYY-MM-01) |
| `ВидУчетаВремени` | String | Да | Тип времени: "Рабочее время", "В" (выходной), "Р" (рабочий) |
| `ДополнительноеЗначение` | Integer | Да | Количество рабочих часов (0 для выходных) |
| `ВремяНачалоРаботы` | String (TIME) | Условно* | Время начала смены (формат: HH:MM:SS) |
| `ВремяЗавершениеРаботы` | String (TIME) | Условно* | Время окончания смены (формат: HH:MM:SS) |

> **\* Условно обязательное:** Если время не передано из 1С, система попытается извлечь его из `НаименованиеГрафика` (например: "09:00-18:00/MG" → начало: 09:00, конец: 18:00). Для выходных дней (`ВидУчетаВремени = "В"`) время может быть NULL.

### 📤 Структура ответа

**Успешный импорт:**
```json
{
  "success": true,
  "message": "Импорт завершен успешно",
  "statistics": {
    "totalSchedulesReceived": 2,
    "totalSchedulesProcessed": 2,
    "totalSchedulesUpdated": 1,
    "totalWorkDaysInserted": 730,
    "errorsCount": 0
  },
  "exportDate": "2025-10-11T10:30:00",
  "errors": null
}
```

**Импорт с ошибками:**
```json
{
  "success": true,
  "message": "Импорт завершен успешно",
  "statistics": {
    "totalSchedulesReceived": 3,
    "totalSchedulesProcessed": 2,
    "totalSchedulesUpdated": 1,
    "totalWorkDaysInserted": 500,
    "errorsCount": 1
  },
  "exportDate": "2025-10-11T10:30:00",
  "errors": [
    "Неполные данные для графика: График без кода"
  ]
}
```

**Ошибка валидации:**
```json
{
  "success": false,
  "error": "Нет данных для импорта. Массив \"Графики\" отсутствует или пуст."
}
```

### 🔄 Логика работы импорта

1. **Валидация данных** - проверка наличия обязательных полей
2. **Удаление старых записей** - для каждого `КодГрафика` удаляются все существующие записи
3. **Вставка новых данных** - для каждого дня графика создается новая запись
4. **Транзакции** - каждый график обрабатывается в отдельной транзакции (при ошибке откатывается только один график)

### ⚡ Производительность

- **1 график с 365 днями** ≈ 2-3 секунды
- **100 графиков** ≈ 3-5 минут
- **158 графиков (полная база)** ≈ 5-8 минут

### 💡 Рекомендации

1. **Оптимальный размер пакета:** 50-100 графиков за запрос
2. **Расписание выгрузки:** 1 раз в сутки (ночью) или по запросу
3. **Обработка ошибок:** При получении `errorsCount > 0` - проверить массив `errors`
4. **Повторная выгрузка:** Если график уже существует - он будет полностью заменен новыми данными

### 🧪 Пример кода 1С для выгрузки

```bsl
// Процедура выгрузки графиков работы в HR Time Tracking
Процедура ВыгрузитьГрафикиРаботы() Экспорт

    // Подготовка данных
    ДанныеВыгрузки = Новый Структура;
    ДанныеВыгрузки.Вставить("ДатаВыгрузки", ТекущаяДата());

    МассивГрафиков = Новый Массив;

    // Выборка графиков из 1С
    Запрос = Новый Запрос;
    Запрос.Текст =
    "ВЫБРАТЬ
    |   ГрафикиРаботы.Ссылка КАК График,
    |   ГрафикиРаботы.Наименование КАК НаименованиеГрафика,
    |   ГрафикиРаботы.Код КАК КодГрафика
    |ИЗ
    |   Справочник.ГрафикиРаботы КАК ГрафикиРаботы
    |ГДЕ
    |   НЕ ГрафикиРаботы.ПометкаУдаления";

    РезультатЗапроса = Запрос.Выполнить();
    ВыборкаГрафиков = РезультатЗапроса.Выбрать();

    Пока ВыборкаГрафиков.Следующий() Цикл

        СтруктураГрафика = Новый Структура;
        СтруктураГрафика.Вставить("НаименованиеГрафика", ВыборкаГрафиков.НаименованиеГрафика);
        СтруктураГрафика.Вставить("КодГрафика", Строка(ВыборкаГрафиков.График.УникальныйИдентификатор()));

        // Получаем рабочие дни графика на весь год
        МассивРабочихДней = Новый Массив;

        НачалоГода = НачалоГода(ТекущаяДата());
        КонецГода = КонецГода(ТекущаяДата());

        ТекущаяДата = НачалоГода;
        Пока ТекущаяДата <= КонецГода Цикл

            // Получаем данные о рабочем дне из графика
            ДанныеДня = ПолучитьДанныеРабочегоДняПоГрафику(ВыборкаГрафиков.График, ТекущаяДата);

            СтруктураДня = Новый Структура;
            СтруктураДня.Вставить("Дата", Формат(ТекущаяДата, "ДФ=yyyy-MM-dd"));
            СтруктураДня.Вставить("Месяц", Формат(НачалоМесяца(ТекущаяДата), "ДФ=yyyy-MM-dd"));
            СтруктураДня.Вставить("ВидУчетаВремени", ДанныеДня.ВидВремени);
            СтруктураДня.Вставить("ДополнительноеЗначение", ДанныеДня.КоличествоЧасов);
            СтруктураДня.Вставить("ВремяНачалоРаботы",
                ?(ЗначениеЗаполнено(ДанныеДня.ВремяНачала),
                  Формат(ДанныеДня.ВремяНачала, "ДФ=HH:mm:ss"),
                  Null));
            СтруктураДня.Вставить("ВремяЗавершениеРаботы",
                ?(ЗначениеЗаполнено(ДанныеДня.ВремяОкончания),
                  Формат(ДанныеДня.ВремяОкончания, "ДФ=HH:mm:ss"),
                  Null));

            МассивРабочихДней.Добавить(СтруктураДня);

            ТекущаяДата = ТекущаяДата + 86400; // +1 день
        КонецЦикла;

        СтруктураГрафика.Вставить("РабочиеДни", МассивРабочихДней);
        МассивГрафиков.Добавить(СтруктураГрафика);

    КонецЦикла;

    ДанныеВыгрузки.Вставить("КоличествоГрафиков", МассивГрафиков.Количество());
    ДанныеВыгрузки.Вставить("Графики", МассивГрафиков);

    // Отправка данных в HR Time Tracking
    Соединение = Новый HTTPСоединение("madlen.space", 443, , , , 60, Новый ЗащищенноеСоединениеOpenSSL);

    Запрос = Новый HTTPЗапрос("/api/admin/schedules/import-1c");
    Запрос.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");

    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.УстановитьСтроку();
    ЗаписатьJSON(ЗаписьJSON, ДанныеВыгрузки);
    JSONСтрока = ЗаписьJSON.Закрыть();

    Запрос.УстановитьТелоИзСтроки(JSONСтрока, КодировкаТекста.UTF8);

    Попытка
        Ответ = Соединение.ОтправитьДляОбработки(Запрос);

        Если Ответ.КодСостояния = 200 Тогда
            ЧтениеJSON = Новый ЧтениеJSON;
            ЧтениеJSON.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку());
            РезультатОтвета = ПрочитатьJSON(ЧтениеJSON);
            ЧтениеJSON.Закрыть();

            Если РезультатОтвета.success Тогда
                Сообщить("Выгрузка успешно завершена!");
                Сообщить("Обработано графиков: " + РезультатОтвета.statistics.totalSchedulesProcessed);
                Сообщить("Вставлено дней: " + РезультатОтвета.statistics.totalWorkDaysInserted);

                Если РезультатОтвета.statistics.errorsCount > 0 Тогда
                    Сообщить("Ошибок: " + РезультатОтвета.statistics.errorsCount);
                    Для Каждого Ошибка Из РезультатОтвета.errors Цикл
                        Сообщить("  - " + Ошибка);
                    КонецЦикла;
                КонецЕсли;
            Иначе
                ВызватьИсключение "Ошибка выгрузки: " + РезультатОтвета.error;
            КонецЕсли;
        Иначе
            ВызватьИсключение "Ошибка HTTP: " + Ответ.КодСостояния;
        КонецЕсли;
    Исключение
        Сообщить("Ошибка при выгрузке графиков: " + ОписаниеОшибки());
    КонецПопытки;

КонецПроцедуры
```

## 👥 2. Обновление данных сотрудников

### Обновление ИИН и ФОТ сотрудников

**Endpoint:** `POST /api/admin/employees/update-iin`

**Описание:** Массовое обновление персональных данных сотрудников (ИИН, ФОТ) из 1С.

### 📥 Структура запроса

```json
[
  {
    "table_number": "АП00-00467",
    "iin": "830909401891",
    "payroll": 212338.00
  },
  {
    "table_number": "АП00-00003",
    "iin": "123456789012",
    "payroll": 350000.50
  }
]
```

### 📋 Описание полей

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `table_number` | String | Да | Табельный номер сотрудника (уникальный идентификатор) |
| `iin` | String | Да | ИИН (Индивидуальный идентификационный номер, 12 цифр) |
| `payroll` | Decimal | Да | Фонд оплаты труда (ФОТ) в тенге |

### 📤 Структура ответа

**Успешное обновление:**
```json
{
  "success": true,
  "message": "Данные сотрудников обновлены",
  "updated": 2,
  "notFound": 0,
  "errors": []
}
```

**Обновление с ошибками:**
```json
{
  "success": true,
  "message": "Данные сотрудников обновлены",
  "updated": 1,
  "notFound": 1,
  "errors": [
    "Сотрудник не найден: АП00-99999"
  ]
}
```

### 🧪 Пример кода 1С

```bsl
Процедура ОбновитьДанныеСотрудников() Экспорт

    МассивСотрудников = Новый Массив;

    Запрос = Новый Запрос;
    Запрос.Текст =
    "ВЫБРАТЬ
    |   Сотрудники.ТабельныйНомер КАК table_number,
    |   Сотрудники.ИНН КАК iin,
    |   Сотрудники.ФОТ КАК payroll
    |ИЗ
    |   Справочник.Сотрудники КАК Сотрудники
    |ГДЕ
    |   НЕ Сотрудники.ПометкаУдаления
    |   И Сотрудники.Уволен = ЛОЖЬ";

    РезультатЗапроса = Запрос.Выполнить();
    ВыборкаСотрудников = РезультатЗапроса.Выбрать();

    Пока ВыборкаСотрудников.Следующий() Цикл
        СтруктураСотрудника = Новый Структура;
        СтруктураСотрудника.Вставить("table_number", ВыборкаСотрудников.table_number);
        СтруктураСотрудника.Вставить("iin", ВыборкаСотрудников.iin);
        СтруктураСотрудника.Вставить("payroll", ВыборкаСотрудников.payroll);
        МассивСотрудников.Добавить(СтруктураСотрудника);
    КонецЦикла;

    // Отправка данных
    Соединение = Новый HTTPСоединение("madlen.space", 443, , , , 60, Новый ЗащищенноеСоединениеOpenSSL);
    Запрос = Новый HTTPЗапрос("/api/admin/employees/update-iin");
    Запрос.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");

    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.УстановитьСтроку();
    ЗаписатьJSON(ЗаписьJSON, МассивСотрудников);
    Запрос.УстановитьТелоИзСтроки(ЗаписьJSON.Закрыть(), КодировкаТекста.UTF8);

    Ответ = Соединение.ОтправитьДляОбработки(Запрос);

    Если Ответ.КодСостояния = 200 Тогда
        ЧтениеJSON = Новый ЧтениеJSON;
        ЧтениеJSON.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку());
        Результат = ПрочитатьJSON(ЧтениеJSON);

        Сообщить("Обновлено сотрудников: " + Результат.updated);
        Если Результат.notFound > 0 Тогда
            Сообщить("Не найдено: " + Результат.notFound);
        КонецЕсли;
    КонецЕсли;

КонецПроцедуры
```

## 📅 3. Назначение графиков сотрудникам

### 3.1 Назначение графика одному сотруднику

**Endpoint:** `POST /api/admin/schedules/assign-employee`

### 📥 Структура запроса

```json
{
  "employee_number": "АП00-00467",
  "schedule_code": "f7167c0a-eebb-11ef-90da-3cecef8cc60b",
  "start_date": "2025-01-01",
  "end_date": null
}
```

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `employee_number` | String | Да | Табельный номер сотрудника |
| `schedule_code` | UUID String | Да | Код графика из work_schedules_1c |
| `start_date` | String (DATE) | Да | Дата начала действия графика (YYYY-MM-DD) |
| `end_date` | String (DATE) | Нет | Дата окончания (NULL = бессрочно) |

### 📤 Структура ответа

```json
{
  "success": true,
  "message": "График успешно назначен сотруднику",
  "assignment": {
    "id": 423,
    "employee_number": "АП00-00467",
    "schedule_code": "f7167c0a-eebb-11ef-90da-3cecef8cc60b",
    "start_date": "2025-01-01",
    "end_date": null
  }
}
```

### 3.2 Массовое назначение графиков

**Endpoint:** `POST /api/admin/schedules/assign-employees-batch`

### 📥 Структура запроса

```json
{
  "assignments": [
    {
      "employee_number": "АП00-00467",
      "schedule_code": "f7167c0a-eebb-11ef-90da-3cecef8cc60b",
      "start_date": "2025-01-01",
      "end_date": null
    },
    {
      "employee_number": "АП00-00003",
      "schedule_code": "52a4bc15-eace-11ef-90da-3cecef8cc60b",
      "start_date": "2025-01-01",
      "end_date": "2025-12-31"
    }
  ]
```

## ⚠️ 6. Коды ошибок

| Код | Описание | Решение |
|-----|----------|---------|
| `400` | Bad Request - невалидные данные | Проверить формат JSON и обязательные поля |
| `404` | Not Found - объект не найден | Проверить существование графика/сотрудника |
| `413` | Payload Too Large | Уменьшить размер пакета (макс. 500MB) |
| `500` | Internal Server Error | Связаться с администратором системы |
| `503` | Service Unavailable | Повторить запрос через некоторое время |

### Типичные ошибки:

**Ошибка 1:** "Неполные данные для графика"
```json
{
  "success": false,
  "error": "Неполные данные для графика: График 10:00-18:00"
}
```
**Решение:** Проверить наличие полей `НаименованиеГрафика`, `КодГрафика`, `РабочиеДни`

---

**Ошибка 2:** "Сотрудник не найден"
```json
{
  "success": false,
  "error": "Сотрудник не найден: АП00-99999"
}
```
**Решение:** Проверить правильность табельного номера

---

**Ошибка 3:** "График не существует"
```json
{
  "success": false,
  "error": "График с кодом f7167c0a-xxxx не найден в системе"
}
```
**Решение:** Сначала импортировать график через `/api/admin/schedules/import-1c`
