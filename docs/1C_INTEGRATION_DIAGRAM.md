## 📊 Детальная схема данных

### 1. Импорт графиков работы

```
1С: ГрафикиРаботы                           HR System: work_schedules_1c
┌──────────────────────────┐                ┌─────────────────────────────┐
│ • Наименование           │                │ schedule_name               │
│ • Код (UUID)             │   ────────►    │ schedule_code (UUID)        │
│ • РабочиеДни[]           │                │ work_date                   │
│   ├─ Дата                │                │ work_start_time             │
│   ├─ ВидУчетаВремени     │                │ work_end_time               │
│   ├─ КоличествоЧасов     │                │ work_hours                  │
│   ├─ ВремяНачала         │                │ time_type                   │
│   └─ ВремяОкончания      │                │ work_month                  │
└──────────────────────────┘                └─────────────────────────────┘

Пример трансформации:

1С JSON:                                    PostgreSQL запись:
{                                           INSERT INTO work_schedules_1c
  "НаименованиеГрафика":                    VALUES (
    "09:00-18:00/MG вх-сб,вс",               '09:00-18:00/MG вх-сб,вс',
  "КодГрафика":                               '52a4bc15-eace-11ef-90da...',
    "52a4bc15-eace-11ef-90da-3cecef8cc60b",  '2025-10-11',
  "РабочиеДни": [{                            '2025-10-01',
    "Дата": "2025-10-11",                     'Рабочее время',
    "ВидУчетаВремени": "Рабочее время",       8,
    "ДополнительноеЗначение": 8,              '09:00:00',
    "ВремяНачалоРаботы": "09:00:00",          '18:00:00'
    "ВремяЗавершениеРаботы": "18:00:00"      );
  }]
}
```

### 2. Обновление данных сотрудников

```
1С: Сотрудники                              HR System: employees
┌──────────────────────────┐                ┌─────────────────────────────┐
│ • ТабельныйНомер         │                │ table_number (PK)           │
│ • ИНН                    │   ────────►    │ iin (12 digits)             │
│ • ФОТ (Оклад)            │                │ payroll (decimal)           │
│ • ПолноеИмя              │                │ full_name                   │
│ • Подразделение          │                │ object_code                 │
│ • Должность              │                │ staff_position_code         │
└──────────────────────────┘                └─────────────────────────────┘

Логика обновления:
1. Поиск по table_number (уникальный)
2. UPDATE если найден
3. Пропуск если не найден (ошибка в логах)
```

---

### 3. Назначение графиков сотрудникам

```
1С: НазначениеГрафиковРаботы               HR System: employee_schedule_assignments
┌──────────────────────────┐               ┌─────────────────────────────────────┐
│ • Сотрудник (ссылка)     │               │ employee_number (FK)                │
│ • График (ссылка)        │  ────────►    │ schedule_code (FK)                  │
│ • ДатаНачала             │               │ start_date                          │
│ • ДатаОкончания          │               │ end_date (NULL = бессрочно)         │
└──────────────────────────┘               └─────────────────────────────────────┘

Связи:
employee_number ──► employees.table_number
schedule_code   ──► work_schedules_1c.schedule_code
```

## 🔍 Процесс получения графика для сотрудника

```
Запрос: "Какой график у сотрудника АП00-00467 на 2025-10-11?"

Шаг 1: Найти сотрудника
┌─────────────────────────────────────┐
│ SELECT * FROM employees             │
│ WHERE table_number = 'АП00-00467'   │
└──────────────┬──────────────────────┘
               │
               ▼
       Сотрудник найден

Шаг 2: Найти активное назначение графика
┌──────────────────────────────────────────────────────────┐
│ SELECT * FROM employee_schedule_assignments              │
│ WHERE employee_number = 'АП00-00467'                     │
│   AND '2025-10-11' BETWEEN start_date                    │
│                        AND COALESCE(end_date, '9999-12-31')
└──────────────┬───────────────────────────────────────────┘
               │
               ▼
       Назначение найдено
       schedule_code = 'f7167c0a-eebb-11ef-90da-3cecef8cc60b'

Шаг 3: Получить детали графика на дату
┌──────────────────────────────────────────────────────────┐
│ SELECT * FROM work_schedules_1c                          │
│ WHERE schedule_code = 'f7167c0a-eebb-11ef-90da-...'      │
│   AND work_date = '2025-10-11'                           │
└──────────────┬───────────────────────────────────────────┘
               │
               ▼
       ┌───────────────────────────────────────┐
       │ График на 2025-10-11:                 │
       │ • Название: "10:00-00:00/City mall"   │
       │ • Время: 10:00 - 00:00                │
       │ • Часов: 12                           │
       │ • Тип: Рабочее время                  │
       └───────────────────────────────────────┘
```

## 📅 Временная шкала синхронизации

```
День недели:   ПН        ВТ        СР        ЧТ        ПТ        СБ        ВС
             ═════════════════════════════════════════════════════════════════

02:00         🔄         📊        📊        📊        📊        💤        💤
             ПОЛНАЯ     ЧАСТИЧ    ЧАСТИЧ    ЧАСТИЧ    ЧАСТИЧ
             СИНХР.     СИНХР.    СИНХР.    СИНХР.    СИНХР.

Операции:

🔄 Полная синхронизация (ПН, ~10-15 мин):
   1. ✅ Импорт графиков работы        (~8 мин)
   2. ✅ Обновление данных сотрудников (~2 мин)
   3. ✅ Назначение графиков           (~5 мин)

📊 Частичная синхронизация (ВТ-ПТ, ~2 мин):
   1. ✅ Обновление данных сотрудников

💤 Выходные:
   - Синхронизация не выполняется
   - Система работает в штатном режиме
```


```
┌─────────────────────────────────────────────────────────────┐
│  Операция                    │  Время на 1 запись           │
├──────────────────────────────┼──────────────────────────────┤
│  1 график (365 дней)         │  ~2-3 секунды                │
│  1 сотрудник (обновление)    │  ~0.01 секунды               │
│  1 назначение графика        │  ~0.02 секунды               │
└─────────────────────────────────────────────────────────────┘

Примеры полной выгрузки:

• 158 графиков    = ~5-8 минут
• 431 сотрудник   = ~4 секунды
• 2133 назначения = ~40 секунд

Итого полная синхронизация: ~10-15 минут
```
