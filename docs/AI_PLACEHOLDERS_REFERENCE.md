# 📋 Справочник плейсхолдеров для AI-промптов

## 🎯 Основные плейсхолдеры данных

### **1. `{forecast}` - Прогнозы продаж**
**Содержит:** Прогнозы продаж по дням с фактическими результатами

**Структура данных:**
```json
[
  {
    "date": "2025-07-10",
    "forecast_sales": 850000,      // Прогнозируемая выручка в тенге
    "actual_sales": 920000,        // Фактическая выручка в тенге
    "deviation": 70000,            // Отклонение в тенге
    "deviation_percent": 8.2       // Отклонение в процентах
  },
  {
    "date": "2025-07-11", 
    "forecast_sales": 760000,
    "actual_sales": 642000,
    "deviation": -118000,
    "deviation_percent": -15.5
  }
]
```

**Доступен для агентов:** SalesAnalysisAgent, PayrollAnalysisAgent

---

### **2. `{plan_vs_fact}` - Сравнение план vs факт**
**Содержит:** Сравнение плановых и фактических показателей

**Структура данных:**
```json
[
  {
    "date": "2025-07-10",
    "plan": 800000,               // Плановая выручка
    "fact": 920000,               // Фактическая выручка
    "deviation": 120000,          // Отклонение от плана
    "deviation_percent": 15.0,    // Процент отклонения
    "status": "above_plan"        // Статус: above_plan/below_plan/on_target
  }
]
```

**Доступен для агентов:** SalesAnalysisAgent

---

### **3. `{hourly_sales}` - Почасовые продажи**
**Содержит:** Средние продажи по часам для будних и выходных дней

**Структура данных:**
```json
[
  {
    "hour": "08:00",
    "weekday_sales": 45000,       // Средние продажи в будни
    "weekend_sales": 32000,       // Средние продажи в выходные
    "peak_indicator": false       // Является ли пиковым часом
  },
  {
    "hour": "13:00",
    "weekday_sales": 120000,
    "weekend_sales": 85000, 
    "peak_indicator": true
  },
  {
    "hour": "22:00",
    "weekday_sales": 65000,
    "weekend_sales": 95000,
    "peak_indicator": false
  }
]
```

**Доступен для агентов:** SalesAnalysisAgent, StaffingAgent

---

### **4. `{payroll}` - ФОТ и смены сотрудников**
**Содержит:** Данные о зарплатах, сменах и расходах на персонал

**Структура данных:**
```json
[
  {
    "employee_id": "12345",
    "employee_name": "Иванов Иван Иванович",
    "position": "Официант",
    "total_salary": 450000,       // Общая зарплата за период
    "shifts": [
      {
        "date": "2025-07-10",
        "start_time": "10:00",
        "end_time": "22:00", 
        "hours": 12,
        "shift_cost": 37500,      // Стоимость смены
        "schedule_type": "основная смена"
      }
    ],
    "total_hours": 84,            // Общее количество часов
    "hourly_rate": 5357          // Ставка за час
  }
]
```

**Доступен для агентов:** PayrollAnalysisAgent, StaffingAgent

---

### **5. `{reviews}` - Отзывы клиентов**
**Содержит:** Свежие отзывы клиентов с разных платформ

**Структура данных:**
```json
[
  {
    "id": "rev_001",
    "date": "2025-07-10",
    "rating": 4.5,               // Оценка от 1 до 5
    "text": "Отличная еда и атмосфера, но немного долго ждали заказ",
    "source": "2gis",           // Источник: 2gis, google, yandex
    "sentiment": "positive",     // positive/negative/neutral
    "keywords": ["еда", "атмосфера", "ожидание"]
  },
  {
    "id": "rev_002", 
    "date": "2025-07-09",
    "rating": 2.0,
    "text": "Кофе остыл, персонал невежливый",
    "source": "google",
    "sentiment": "negative",
    "keywords": ["кофе", "персонал", "сервис"]
  }
]
```

**Доступен для агентов:** ReputationAgent

---

### **6. `{department_info}` - Информация о подразделении**
**Содержит:** Базовая информация о заведении

**Структура данных:**
```json
{
  "department_id": "4cb558ca-a8bc-4b81-871e-043f65218c50",
  "name": "Кафе City Mall",
  "type": "кафе",              // Тип заведения
  "address": "г. Алматы, ТРЦ City Mall",
  "seating_capacity": 50,      // Количество посадочных мест
  "opening_hours": "08:00-23:00",
  "cuisine_type": "европейская",
  "price_segment": "средний"
}
```

**Доступен через:** `{all_data}` в NarrativeAgent

## 🤖 Специальные плейсхолдеры

### **7. `{agent_results}` - Результаты других агентов**
**Содержит:** Результаты анализа от предыдущих агентов

**Структура данных:**
```json
{
  "SalesAnalysisAgent": "АНАЛИЗ ПРОДАЖ:\n- Выручка растет на 12% в будни\n- Сильные дни: среда-пятница\n- Слабые дни: понедельник, выходные\n- Пик продаж в 13:00-16:00",
  
  "PayrollAnalysisAgent": "АНАЛИЗ ФОТ:\n- ФОТ составляет 14% от выручки (норма 10-12%)\n- Перерасход на 2% из-за избытка персонала\n- Самые дорогие смены: 10:00-22:00",
  
  "StaffingAgent": "ОПТИМИЗАЦИЯ ПЕРСОНАЛА:\n- Перегрузка в пик 13:00-16:00\n- Недогрузка утром 08:00-11:00\n- Рекомендуется сменить график на 11:00-23:00",
  
  "ReputationAgent": "АНАЛИЗ ОТЗЫВОВ:\n- Средняя оценка: 4.2/5\n- Основные жалобы: скорость обслуживания\n- Хвалят: качество еды, атмосферу"
}
```

**Доступен для агентов:** OptimizationAgent, NarrativeAgent

---

### **8. `{all_data}` - Все данные от MCP API**
**Содержит:** Полный набор всех данных

**Структура данных:**
```json
{
  "forecast": [...],           // Массив прогнозов
  "plan_vs_fact": [...],       // Массив сравнений план/факт
  "hourly_sales": [...],       // Массив почасовых продаж
  "payroll": [...],           // Массив данных по ФОТ
  "reviews": [...],           // Массив отзывов
  "department_info": {...},   // Объект с информацией о подразделении
  "metadata": {
    "request_time": "2025-07-14T10:30:00Z",
    "period": {
      "start": "2025-07-10",
      "end": "2025-07-13"
    },
    "total_records": 156
  }
}
```

**Доступен для агентов:** NarrativeAgent

## 🎯 Применение плейсхолдеров по агентам

### **📈 SalesAnalysisAgent**
**Доступные плейсхолдеры:** `{forecast}`, `{plan_vs_fact}`, `{hourly_sales}`

**Пример промпта:**
```
Тебе даны данные:
— Прогнозы по дням: {forecast}  
— Сравнение план/факт: {plan_vs_fact}
— Почасовые продажи: {hourly_sales}

Проанализируй:
- Дни с отклонением > 20%
- Пиковые часы продаж
- Тренды роста/падения
```

### **💰 PayrollAnalysisAgent** 
**Доступные плейсхолдеры:** `{payroll}`, `{forecast}`

**Пример промпта:**
```
Данные для анализа затрат:
— ФОТ и смены: {payroll}
— Прогнозы продаж: {forecast}

Рассчитай:
- % ФОТ от выручки по дням
- Самые дорогие смены
- Эффективность персонала
```

### **👥 StaffingAgent**
**Доступные плейсхолдеры:** `{payroll}`, `{hourly_sales}`

**Пример промпта:**
```
Данные о персонале:
— Смены сотрудников: {payroll}
— Почасовые продажи: {hourly_sales}

Оптимизируй:
- Распределение персонала по часам
- Соответствие нагрузки и количества сотрудников
- Рекомендации по графикам
```

### **⭐ ReputationAgent**
**Доступные плейсхолдеры:** `{reviews}`

**Пример промпта:**
```
Отзывы клиентов: {reviews}

Проанализируй:
- Общую статистику оценок
- Топ-3 проблемы
- Топ-3 сильные стороны
- Тренды в отзывах
```

### **🎯 OptimizationAgent**
**Доступные плейсхолдеры:** `{agent_results}`

**Пример промпта:**
```
Выводы других агентов: {agent_results}

Создай план оптимизации:
- 5 конкретных действий
- Приоритизация по важности
- Ожидаемый эффект от каждого
```

### **📊 NarrativeAgent**
**Доступные плейсхолдеры:** `{all_data}`, `{agent_results}`

**Пример промпта:**
```
Все данные: {all_data}
Анализ агентов: {agent_results}

Составь executive summary:
- Краткое резюме (3-4 предложения)
- Ключевые показатели
- Основные проблемы и возможности
- План действий
```

## 💡 Практические советы

### **✅ Хорошие практики:**
- Указывайте конкретные поля: "из `{forecast}` возьми только deviation_percent > 15"
- Просите структурированный вывод: "создай таблицу из `{hourly_sales}`"
- Комбинируйте данные: "сравни `{payroll}` с `{hourly_sales}` по часам"
- Используйте условия: "если в `{reviews}` рейтинг < 3, выдели проблемы"

### **✅ Примеры продвинутых промптов:**
```
Создай таблицу эффективности:
| Час | Продажи (будни) | Продажи (выходные) | Количество сотрудников | Эффективность |

Используй данные: {hourly_sales} и {payroll}
```

```
Из {plan_vs_fact} выбери только дни с отклонением > 15% и объясни возможные причины.
```

### **❌ Ограничения:**
- ❌ Нельзя использовать несуществующие плейсхолдеры
- ❌ Нельзя обращаться к вложенным полям через точку: `{forecast.sales}`
- ❌ Плейсхолдеры автоматически заменяются на JSON - нельзя их модифицировать в промпте
- ❌ Нельзя использовать плейсхолдеры агентов, которые не указаны в их `data_fields`
